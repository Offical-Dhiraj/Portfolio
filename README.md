## 📌 Overview

This project is a modern, responsive and production-ready personal portfolio website designed to showcase my skills, projects, technical experience, education, GitHub activity and professional profile.

The application follows a full-stack architecture where the React frontend communicates with a Node.js and Express backend through REST APIs. Portfolio data such as profile information, projects and technical skills is stored in MongoDB Atlas, while GitHub repositories are dynamically fetched using the GitHub REST API.

The application is deployed using **Vercel for the frontend** and **Render for the backend**.
